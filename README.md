## ✨ About

**RT FORMS** lets you build forms, quizzes and surveys, share them with anyone, and review every response, all in a clean, fast, mobile-friendly interface. It is built with plain **HTML5, CSS3 and JavaScript**, so there is no framework, no build step and nothing to install.

---

## 🚀 Features

| | Feature | Description |
|---|---|---|
| 🛠️ | **Form Builder** | Create custom forms quickly with an easy builder |
| 💬 | **Feedback Forms** | Collect opinions and ratings in seconds |
| 🧠 | **Quizzes** | Build quizzes and test knowledge |
| 📊 | **Surveys** | Gather structured answers from your audience |
| 🧾 | **Registrations** | Create sign-up and registration forms |
| 🔗 | **Easy Sharing** | Share your form and start collecting responses |
| 📥 | **Response Review** | Review every response in one place |
| 📱 | **Fully Responsive** | Works smoothly on mobile, tablet and desktop |
| ⚡ | **Zero Dependencies** | Pure vanilla stack, light and fast |

## ⚙️ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/shahrishabh1513-jsk/rt-forms.git
```

**2. Open the project folder**

```bash
cd rt-forms
```

**3. Run it**

Just open `index.html` in your browser, or use a local server:

```bash
# Python
python -m http.server 5500

# or VS Code → "Live Server" extension → Go Live
```

Then visit **http://localhost:5500** 🎉
