## 🌟 About The Project

**RT FORMS** lets anyone design, share and collect responses through clean, good-looking online forms — no backend setup, no heavy frameworks. Open the page, build your form, and share it.

It is lightweight, fast, works on every screen size, and is easy to customise because it is written in plain HTML, CSS and JavaScript.

## 🚀 Getting Started

### Prerequisites

Just a modern web browser (Chrome, Edge, Firefox, Safari). No installation or build step needed.

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/shahrishabh1513-jsk/rt-forms.git

# 2. Go into the project folder
cd rt-forms

# 3. Open index.html in your browser
#    (double-click the file, or use a local server such as VS Code Live Server)
```

### Deploy on GitHub Pages

1. Go to **Settings → Pages** in your repository
2. Under **Source**, choose the `main` branch and `/ (root)` folder
3. Click **Save** — your site goes live at `https://<username>.github.io/rt-forms/`
