## 🌟 About The Project

<table width="100%">
  <tr>
    <th align="left">🔴 🟡 🟢 &nbsp;&nbsp;&nbsp; <sub>About — RT FORMS</sub></th>
  </tr>
  <tr>
    <td>
      <b>RT FORMS</b> lets anyone design, share and collect responses through clean, good-looking online forms —
      no backend setup, no heavy frameworks. Open the page, build your form, and share it.
      It is lightweight, fast, works on every screen size, and is easy to customise because it is plain HTML, CSS and JavaScript.
    </td>
  </tr>

## 🚀 Getting Started

<table width="100%">
  <tr>
    <th align="left">🔴 🟡 🟢 &nbsp;&nbsp;&nbsp; <sub>Terminal — rt-forms</sub></th>
  </tr>
  <tr>
    <td>

```bash
# 1. Clone the repository
git clone https://github.com/shahrishabh1513-jsk/rt-forms.git

# 2. Go into the project folder
cd rt-forms

# 3. Open it in your browser
open index.html          # macOS
# start index.html       # Windows
# xdg-open index.html    # Linux
```

</td>
  </tr>
</table>

**Deploy on GitHub Pages:** go to **Settings → Pages**, choose the `main` branch and `/ (root)`, then **Save**. Your site goes live at `https://<username>.github.io/rt-forms/`.
